# Vercel + MongoDB

Vercel project: `nosleepclub-nasa-spherex`, root `web/`, public production, preview protected by SSO. The site uses static HTML/CSS/JS and Python Functions at `/api/reviews`, `/api/observations`, and `/api/frame`, in Singapore region `sin1`. The web runtime does not use Node. Version 0.10 separately installs Astropy/NumPy/Pillow for FITS/WCS reading and image rendering; heavier scientific fitting still runs offline. See Vercel’s [official Python API directory guidance](https://vercel.com/docs/functions/runtimes/python/api-directory).

Dedicated MongoDB Atlas project `NoSleepClub_NASA_SPHEREx`, M0 cluster `nosleepclub-spherex` on AWS Singapore. Database: `nosleepclub_nasa_spherex`; the database user has `readWrite` access only to this database and cluster. `MONGODB_URI` is a **sensitive production-only** Vercel variable; it is not present in the frontend, repository, or preview. Do not log the URI, cookies, or review content.

The user explicitly approved storing the credential in this project and allowing `0.0.0.0/0` so Vercel can connect from dynamic egress IPs. Connections still require TLS and authentication; this allowlist permits any IP to attempt a connection if the endpoint is known. The paid Static IP option is not enabled. If production data needs narrower network access, design a dedicated egress/proxy option and approve its cost first.

The API issues a `__Host-` session cookie with Secure, HttpOnly, and SameSite=Strict. The database stores only the token hash. There is no public review list and the owner cannot be chosen in the request payload. POST/DELETE check HTTPS Origin/Host; the server validates scene/selection and analysis hashes against a manifest and obtains input-data hashes itself. Limits: 8 KiB request body, 2,000-character note, at most 100 reviews per session, 90 requests per minute per hashed IP, and a 2-minute TTL for rate buckets. Guest sessions are not a substitute for sign-in or bot protection at larger scale.

Reviews expire after 180 days through a TTL index; users can delete and export JSON. Losing the cookie or changing devices makes the same session unrecoverable. If the server fails, retain the local copy and show “Not synced”; do not automatically upload old local data to the cloud. The localhost server still works fully offline and stores reviews locally.

The schema, indexes, and rate limit are created on the API’s first connection. Production QA must check anonymous GET, a saved POST, GET from the same session, denial of access from another session, cross-origin blocking, deletion of QA data, and an empty follow-up GET. Do not test with real user reviews.

## What Did SPHEREx See?

The root page opens the orbit scene. `#about` opens the mission page, `#night-sky` opens the sky view, and `#explore` still opens coordinate search. The first visit to the image-comparison tool loads the legacy workspace scripts. WebGL uses a GLB and Three.js served from the same origin. The CSP adds `blob:` to `connect-src` so Three.js can read textures embedded in the GLB. Full-detector previews and the saved Epsilon DR1 sequence are in `web/assets/mission/` and are built statically with the interface.

The orbit page has a guide, illustrative poster, and logo iris effect. The sky view fills the screen with a data sidebar. A/B comparison uses one camera for both images on the same WCS grid, with a separate observation time and detector for each image. The timeline tab plays images in observation order. [Official challenge review](CHALLENGE_LIVE_REVIEW.md)

Then run the request-limit smoke check and review lifecycle described in the runbook before updating the public URL.
