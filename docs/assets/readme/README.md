## Pitch v3

[Watch / download the original MP4](https://github.com/dakiemdarktharr/nosleepclub_nasa_spherex/releases/download/pitch-v3/Touch-the-Sky-30s-v3.mp4) · [Release page](https://github.com/dakiemdarktharr/nosleepclub_nasa_spherex/releases/tag/pitch-v3)

The final video is hosted as a Release asset to keep the binary out of Git history. Its format is H.264/AAC, 1920 × 1080, 30 fps, 30 seconds. It contains real recorded interactions: Gagoo walking, tablet learning, a quiz answer and feedback, an image wipe, and synchronized image panning. These interactions are accelerated in the edit. The film predates the newer ship/flight interface shown in this README.

Narration uses the ElevenLabs stock Sarah voice with `eleven_v3`, without voice cloning. The title reading is 25% faster than v2 with pitch preserved. The instrumental score is the generated ElevenLabs Music track from v2, mixed beneath speech. No claim of exclusive ownership or blanket MIT licensing is made for generated audio.

Visual sources:

- Actual Touch The Sky application, recorded locally from the project. V3 comparison footage shows processed observations around WISE 0855. The lesson filter diagram is illustrative, not an observation.
- [NASA Goddard / Ernie Wright starfield](https://svs.gsfc.nasa.gov/3895/): catalog-based visualization, not a SPHEREx observation.
- [NASA/JPL-Caltech SPHEREx in orbit](https://science.nasa.gov/photojournal/spherex-in-orbit-artists-concept/): artist's concept.
- Website typography: Be Vietnam Pro, with its bundled SIL Open Font License.

The original production files remain in ignored `data/raw/touch-the-sky-pitch/`. V3 notes take precedence over v1 notes about comparison footage. The pitch describes intended educational impact; it does not claim a classroom study or validated discovery. Source and reuse qualifications in [NOTICE](../../../NOTICE.md) still apply to assets shown inside screenshots and the film.
