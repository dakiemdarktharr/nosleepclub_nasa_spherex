# Native reference-star development protocol

This protocol is committed with its complete design/source/input inventory **before** new native position fits. It uses only the 20 already opened WISE 0855 QR2 D6 cutouts and all 21 previously image-selected Gaia reference stars. It does not open the reserved 30 fields. The old 14-training/7-heldout labels are retained for provenance; neither group is unseen validation. Membership in upstream SPHEREx WCS/ePSF training is unknown.

The fixed denominator is **21 stars × 20 exposures × 2 ePSF variants = 840 attempts**, forming 420 paired cells. The variants use the unchanged official nearest table or the existing bilinear table mixture, with native phase normalization on the full lattice. The target and every retained infrared neighbor have free signed Jy amplitudes; a plane is fitted simultaneously. Background degree, neighbor selection and position search are identical between variants. This is a spatial interpolation diagnostic, not a learned PSF correction.

Every Gaia position uses actual IMAGE MJD-AVG UTC, first-order proper motion and Earth parallax with the five-parameter catalogue covariance. The shared catalogue error across all 20 times is retained as a separate 40×40 component in publication. The legacy Earth-only propagation omits observer/perspective/radial-velocity refinements; it is not a full astrometric uncertainty budget. For each evaluated old training star, its own reference measurement is removed from the legacy translation registration. Old heldout stars use the 14 old training references. This removes direct self-registration; it does not make the reference frame or upstream WCS independent.

The complete old source cohort, two spectral allocations and all exposure identities are verified. Gaia catalogue snapshots must equal the pinned raw catalogue. A single Gaia-ID-matched infrared counterpart within 0.35 common-sky pixels is removed from the neighbor design. Missing/ambiguous counterparts, more than 24 neighbors within 8 common-sky pixels, fewer than 35 valid native pixels, native edge margin below 12 pixels, or fixed-anchor core valid fraction below 0.75 cause terminal preparation failures. No source is removed or replaced after those failures. Both variants share the same pixels, errors, neighbor IDs and registration.

The point solver is the frozen neighbor epoch implementation applied to one native exposure: nine initial starts, ±2.5 common-sky-pixel bounds, Huber 2.5 reweighting up to 20 iterations, and nine final fixed-weight mode starts. Negative flux, failed convergence, boundaries, rank and multimodality remain in the full record. Numerical support is reported separately and never called a valid source or a calibrated probability. No centroid covariance is inferred from these fits.

Three fixed disjoint CLI shards allocate sorted source IDs by index modulo three. Every attempt has an immutable checksummed atomic journal record. Resuming fills only missing keys; terminal failures cannot be selectively rerun. All 840 terminal records are required before final publication. Interrupted work remains incomplete. Runtime packages must match pinned requirements, and fresh CLI workers request one numeric backend thread each; requested settings are not independently measured thread counts.

Publication reports all attempted/completed/failed and paired/common-numerical denominators, local east/north Gaia residuals, vector RMS, median radial error and paired changes. Star and exposure summaries preserve the repeated-measure structure; 840 fits are not 840 independent samples. No arbitrary flux/SNR cut, post-hoc residual clipping, best-source subset, learned correction or scientific model promotion is permitted. Real-star offsets include centroid bias, catalogue propagation approximation, registration and upstream systematics. A smaller residual alone cannot prove the physical PSF or absolute target accuracy.

The immediate follow-through is a separately frozen conditional source-presence calibration/validation study. The prior numerically supported 16.8-arcsec synthetic failure remains published; it is not removed using a rule chosen after seeing it. Neither this star experiment nor the conditional simulations can replace independent field calibration, realistic real-source controls, joint reference covariance or a blind search false-alarm evaluation.

References: the [official IRSA ePSF tutorial](https://caltech-ipac.github.io/irsa-tutorials/spherex-psf/) describes the pixel-convolved ePSF and QR3/QR2 use; this does not certify our bilinear approximation. [Gaia DR3 astrometric transformations](https://gea.esac.esa.int/archive/documentation/GDR3/Data_processing/chap_cu3ast/sec_cu3ast_intro/ssec_cu3ast_intro_tansforms.html) provide the fuller motion/covariance context; our first-order implementation is explicitly narrower.
